02Projects

GOOP — 어린이놀이시설 스마트 지도점검시스템

대표 프로젝트 · 운영중

goop.or.kr · 지자체·교육청 담당자 로그인 후 이용
전자정부 표준프레임워크(eGovFrame) 기반으로 지자체·교육청이 관할 어린이 놀이시설을 지도 위에서 계획-현장점검-이행관리-보고서까지 한 번에 처리하도록 만든 시스템입니다. 약 10개월간 기획부터 백엔드(Spring Boot + MyBatis + PostgreSQL)·프론트엔드(React + Redux) 전체를 혼자 설계·개발·운영했습니다.

Spring Boot 2.7 · eGovFrame 4.2 · MyBatis · PostgreSQL(HikariCP) · Redis · Spring Security + JWT · WebFlux · React 18 · Redux Toolkit · Formik/Yup · React-Konva · ApexCharts/ECharts · react-speech-recognition · react-to-print

핵심 기능 & 문제해결 사례

01

인증/보안 설계. Stateless JWT(HS256) + Redis 세션 레코드로 서버에서 즉시 토큰 무효화 가능. 비밀번호 인증 후 OTP 2차 인증(SMS/메일) 강제, 외부 용역 계정은 액세스 토큰 유효기간을 1일로 차등 적용. 최근 OTP 무한 시도를 막는 계정 잠금(실패 카운트, 429 응답) 진행 중.

02

AI 이미지 분석(RAG). 점검 사진 업로드 시 OpenAI Responses API + 자체 점검지침 Vector Store를 file_search로 연결해 문서 근거 기반으로 점검항목을 자동 판별. 응답을 json_schema로 강제해 파싱 실패 없이 구조화된 결과를 받도록 설계.

03

다중 관할구역 데이터 모델 리팩토링. "지역코드 1개 = 지역명 1개" 가정이 실제로는 한 코드가 두 지자체(광주시·하남시)를 공유하는 사례에서 깨짐을 확인. 지역코드를 리스트 구조로 일반화하고, 중복돼 있던 지역 조회 로직을 별도 region 패키지로 분리(파일 31개, -188/+223라인).

04

레거시 파일 아카이브 연동. 협회의 Windows 공유폴더(SMB) 기반 과거 점검사진 저장소를 붙여 스트리밍 복사로 UUID 파일명 규칙에 맞게 정규화. 전체 목록 반환 방식이 실사용 데이터량에서 문제되자 시설·연도별 분할 조회로 개선.

05

음성 입력(STT) 실사용 버그 수정. 녹음 중지 시 기존 텍스트를 덮어쓰는 버그, 포커스 전환 시 인식 세션이 안 끊기는 버그를 발견해 텍스트 누적 방식 + 언마운트 시 세션 정리로 수정. 6곳에 중복된 버튼 코드를 함수 하나로 통합(순감소 -215라인).

06

사진 위 위해요소 마커 표시. Konva로 점검사진 위에 위험 지점 마커를 찍고 드래그/리사이즈. 좌표를 원본 이미지 비율로 정규화 저장해 화면 크기와 무관하게 위치가 어긋나지 않도록 처리, 저장 시 사진+마커를 합성해 업로드.

07

협회 공식 서식 보고서 인쇄. 표지·목차·시설별 점검 상세·차트가 들어간 3,000줄 규모의 공식 서식을 HTML/CSS로 구현하고 react-to-print로 인쇄 지원. 종이 서식과 셀 단위까지 맞추기 위해 여백을 하나씩 수기로 조정.

08

API 쿼리스트링 인코딩 버그 수정. 문자열 직접 조합 방식이 한글·특수문자에서 파라미터가 깨지는 문제를 axios 기본 파라미터 직렬화(params 옵션)로 교체해 근본적으로 해결.

09

저사양 태블릿 이미지 업로드 실패 대응. 현장 피드백을 받고 업로드 전 클라이언트 단에서 이미지 리사이즈·압축(최대 1024px, 웹워커로 메인 스레드 비차단) 적용. 처리 중 로딩 스피너 표시 및 완료 전 제출 차단으로 중복 업로드·빈 이미지 저장 문제까지 함께 해결.
